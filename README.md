# Data Science Portfolio

I am a veterinarian with a master's degree in Animal Health and Production, expanding my career into Data Science and Data Analytics.

My background in scientific research, experimental design, and quantitative analysis has led me to develop skills in Python, statistical modeling, machine learning, data visualization, SQL, and Power BI.

This portfolio contains selected projects demonstrating the application of these skills to data analysis, predictive modeling, and statistical problems.

## Projects
### 1. Advertising sales prediction with multiple linear regression

A statistical modeling project focused on predicting product sales from advertising expenditures. The analysis includes multiple linear regression, backward feature selection, regression diagnostics, confidence intervals, and out-of-sample evaluation.

**Key techniques:** OLS regression, feature selection, statistical inference, residual diagnostics, R², MAE, RMSE.

[View project](https://github.com/hiram21/advertising-multiple-linear-regression)

---

### 2. Employee attrition prediction with Support Vector Machine

A machine learning classification project focused on predicting employee attrition using Support Vector Machines. The project includes data preprocessing, class imbalance handling, hyperparameter optimization, and model evaluation.

**Key techniques:** SVM, SMOTE, GridSearchCV, cross-validation, confusion matrix, classification metrics.

[View project](https://github.com/hiram21/employee-attrition-svm)

---

### 3. Employee attrition prediction with K-Nearest Neighbors

A classification project using K-Nearest Neighbors to predict employee attrition. The analysis explores model performance and evaluates the classifier using multiple classification metrics.

**Key techniques:** KNN, preprocessing, model evaluation, confusion matrix, ROC curve, AUC.

[View project](https://github.com/hiram21/employee-attrition-knn)

---

### 4. Drug classification with Decision Tree

A multiclass classification project that uses a Decision Tree to predict drug categories from patient characteristics. The project explores the decision rules learned by the model and evaluates its predictive performance.

**Key techniques:** Decision Tree, multiclass classification, model evaluation, decision rules, visualization.

[View project](https://github.com/hiram21/drug-classification-decision-tree)

---

### 5. Inflation data analysis

An exploratory data analysis project examining historical inflation patterns across multiple countries. The project uses data transformation and visualization to compare inflation dynamics across economies.

**Key techniques:** data cleaning, exploratory data analysis, pandas, Matplotlib, Seaborn.

[View project](https://github.com/hiram21/inflation-data-analysis)
